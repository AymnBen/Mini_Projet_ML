## Exercice 1 : NumPy

Dans cet exercice, nous avons utilisé NumPy pour :

- Créer des tableaux de zéros et de uns
- Générer des nombres entre 10 et 50
- Créer une matrice identité
- Créer une matrice 3x3
- Générer des nombres aléatoires
- Calculer la somme d’une matrice
- Calculer l’écart-type
- Calculer la somme des colonnes

## Exercice 2 : Pandas

Dans cet exercice, nous avons utilisé Pandas pour :

- Créer un DataFrame
- Ajouter des index et des colonnes

- Afficher les informations du DataFrame
- Afficher les statistiques descriptives
- Supprimer une ligne
